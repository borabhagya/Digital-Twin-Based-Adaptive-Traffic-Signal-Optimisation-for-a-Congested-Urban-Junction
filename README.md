# Digital-Twin-Based-Adaptive-Traffic-Signal-Optimisation-for-a-Congested-Urban-Junction

A digital-twin-based framework for adaptive traffic signal optimisation at a congested six-arm urban junction.

The system combines AIoT traffic sensing, sensor fusion, a continuously updated digital twin, and constrained Model Predictive Control (MPC) to adapt signal timings to changing college and market demand. The design incorporates maximum-waiting-time fairness and spillback avoidance, with a staged verification pathway from historical replay and simulation to shadow-mode testing and controlled deployment.

This repository contains the interactive web-based prototype accompanying the proposed system. The prototype visualises junction state, traffic scenarios, queue evolution, adaptive signal decisions, performance metrics, system architecture, and the proposed verification and rollout strategy.

Note: The traffic states and performance values shown in the prototype are illustrative and are intended to demonstrate the proposed workflow. They must be replaced with calibrated simulation and field data before real-world deployment.
